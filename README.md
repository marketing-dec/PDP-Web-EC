# PDP-Web-EC

Repositorio de trabajo para diseñar y versionar la nueva página de producto (PDP) de Educación Continua UC.

## Vista previa

El prototipo principal se encuentra en `index.html`.

Para publicarlo con GitHub Pages:

1. Ve a **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama **main** y la carpeta **/(root)**.
4. Guarda los cambios.

La URL esperada será:

https://marketing-dec.github.io/PDP-Web-EC/
