¿Qué aprenderás?

Aplicar técnicas de minería de datos, analítica e inteligencia de negocios para la transformación digital y la gestión guiada por datos.

Diplomado en Ciencia de Datos Aplicada a Negocios

Los desafíos de este ámbito requieren criterios claros para impulsar la transformación digital y una gestión guiada por datos. Desarrollarás capacidades para aplicar minería de datos, analítica e inteligencia de negocios, vinculando el aprendizaje con situaciones profesionales respaldadas por el programa.

Este programa se compone de los siguientes cursos

Fundamentos de Python para Análisis de Datos

Estadística y Machine Learning con R

Visualización de Datos y Business Intelligence

Casos de Negocio y Proyecto Integrador
